# Acceptance Criteria Register

> Optional central register for projects with multiple features. Feature-specific criteria may live beside the feature specification.

| ID | Requirement/feature | Criterion | Status | Verification evidence |
|---|---|---|---|---|

## Status values

- Draft
- Ready
- Verified
- Failed
- Deferred
- Blocked

## Rule

Every non-trivial criterion should be objectively verifiable. Link the evidence to tests, verification reports, screenshots, runtime checks, or other concrete artifacts rather than relying on a subjective statement that the feature "works".
