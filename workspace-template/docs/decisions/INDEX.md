# Architecture Decision Records Index

Each significant durable decision gets its own ADR file in this directory.

## Status meanings

- **Proposed** — under consideration and not yet a project constraint.
- **Accepted** — current authoritative decision.
- **Deprecated** — no longer recommended but not necessarily replaced.
- **Superseded** — replaced by another ADR; preserve history and link the successor.

## Rules

- Never renumber or reuse an ADR number.
- Never silently rewrite history to make an old choice disappear.
- Link new ADRs to relevant requirements, architecture, conventions, and superseded decisions.
- Update the index when ADR status changes.
- An ADR records rationale and trade-offs; code remains the source of actual implementation behavior.
