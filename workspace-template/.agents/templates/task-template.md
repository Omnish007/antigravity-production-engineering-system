# Task Record

```yaml
id: TASK-000
name: <short-name>
type: feature
status: PENDING
priority: P1
owner: <logical-role>
dependencies: []
expectedOutputs: []
acceptanceCriteria: []
verification: []
risks: []
notes: []
```

## Definition of done

- acceptance criteria verified;
- required checks executed;
- diff reviewed;
- blockers recorded if any;
- memory synchronized if durable knowledge changed.
