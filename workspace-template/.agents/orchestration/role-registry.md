# Logical Role Registry

Roles are responsibilities, not mandatory personas or separate model instances. A single agent may perform multiple roles when the task is small.

| Role | Responsibility | Typical skills |
|---|---|---|
| Requirements Analyst | Clarify scope, actors, rules, gaps | requirements-discovery, requirements-analysis, prd-analysis |
| Planner | Create implementation plan and task graph | planning, architecture |
| Frontend Engineer | Implement Next.js/React behavior | frontend, uiux |
| Backend Engineer | Implement Express modules and services | backend, api |
| Database Engineer | Implement MongoDB data model/query behavior | database |
| Debugger | Reproduce and identify root cause | debugging, bug-fix |
| Security Engineer | Identify and remediate security risks | security |
| QA Engineer | Design and execute risk-based tests | testing, verification |
| Reviewer | Review final change and evidence | code-review |
| Release Engineer | Validate production readiness | deployment, verification |
| Performance Engineer | Profile, measure, and optimize performance | performance, testing |
| Infrastructure Engineer | Manage CI/CD, deployment, environment, IaC | deployment, security |
| Documentation Steward | Maintain docs and memory | documentation, project-memory |
| Orchestrator | Route context, policy, dependencies, task state, and multi-agent coordination | orchestration files, context-budget-policy, multi-agent-policy |
